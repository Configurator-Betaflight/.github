## Что такое Betaflight Configurator

**Betaflight Configurator** — это кроссплатформенное приложение (Windows, macOS, Linux), предназначенное для прошивки и конфигурации контроллеров полёта с прошивкой Betaflight. Он позволяет подключить контроллер через USB, обновить прошивку, настроить параметры, такие как PID, фильтры, профили полёта, режимы и многое другое.
Программа поддерживается открытым сообществом и размещена на GitHub под лицензией GPL-3.0. 

---

## Основные возможности

- 📥 Сборка и прошивка контроллера («Firmware Flasher» таб). 
- 🧮 Настройка основных параметров: версия прошивки, платформа, аппаратная цель (Target).  
- ⚙️ Конфигурация периферийных настроек: UART-порты, приёмник, OSD, VTX, LED.  
- 📊 Таб вкладок: Setup (основные данные), Ports, Configuration, PID Tuning, Modes и др.
- 🔧 Поддержка визуализации и загрузки конфигураций, загрузка профилей, резервное копирование настроек.  
- 🧰 Совместимость с широким спектром контроллеров полёта, начиная со STM32 серий.  

---

## Расширенные функции

- 🧭 В облачной версии: PWA-сборка, работа прямо из браузера Chrome/Chromium.

## Как начать

1. Перейдите на страницу релизов на GitHub и скачайте версию под вашу ОС.
2. Установите приложение или распакуйте портативную версию.  
3. Подключите контроллер полёта к компьютеру через USB.  
4. Запустите Betaflight Configurator, выберите «Connect».  
5. На вкладке Firmware Flasher выберите вашу плату и загрузите прошивку.  
6. После прошивки перейдите к вкладке Configuration и настройте параметры, затем вкладка PID Tuning и Modes.  
7. Сохраните профиль и протестируйте на модели.
